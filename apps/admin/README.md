# apps/admin

Plattformadministration der Verevia-Plattform.

## Zweck

Dieses Verzeichnis enthält perspektivisch das Administrationsdashboard für Plattformadministratoren (getrennt von Vereinsadministratoren). Es dient der Verwaltung von Mandanten, Plattformrollen und übergreifenden Einstellungen.

## Status

Es ist noch keine lauffähige Anwendung vorhanden. Dieses Verzeichnis dient aktuell als struktureller Platzhalter für die technische Umsetzung ab Phase 1 der [Roadmap](../../docs/roadmap/Roadmap.md).
