# Sicherheitsrichtlinie

## Sicherheitsprobleme melden

Bitte melde sicherheitsrelevante Probleme **nicht** als öffentliches GitHub-Issue.

Wende dich stattdessen zunächst direkt an den Repository-Inhaber: [@mugglman](https://github.com/mugglman), zum Beispiel über eine private [Sicherheitsmeldung (GitHub Security Advisory)](https://github.com/mugglman/Verevia/security/advisories/new) für dieses Repository.

## Hinweise für Meldungen

- Veröffentliche keine Zugangsdaten, Tokens oder sonstige Geheimnisse in einer Meldung.
- Stelle keine privaten oder personenbezogenen Daten Dritter in Issues oder Kommentaren ein.
- Beschreibe das Problem so konkret wie möglich, damit es nachvollzogen werden kann.

## Unterstützte Versionen

Verevia befindet sich in der frühen Planungs- und Aufbauphase. Es existiert noch keine veröffentlichte Version und keine formale Liste unterstützter Versionen. Diese Angaben werden ergänzt, sobald ein Produktivbetrieb vorbereitet wird (siehe [Roadmap](./docs/roadmap/Roadmap.md)).
