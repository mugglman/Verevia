# packages/utils

Gemeinsame Hilfsfunktionen der Verevia-Plattform.

## Zweck

Dieses Paket enthält perspektivisch geteilte Hilfsfunktionen (z. B. Datums-, String- oder Validierungshilfen), die von mehreren Anwendungen und Paketen im Monorepo genutzt werden.
